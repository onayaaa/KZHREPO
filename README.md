## 五个页面

- **概要** — 订阅者、总时长等数字，年别配信时间、纪念日、月别趋势、配信日历、常见联动对象与游戏、订阅者推移、官方链接。
- **配信** — 每条配信显示封面、标题、时长，可按年 / 月 / 联动对象 / 内容 / 种类（配信、番組、切片、Shorts、歌、演唱会、商业合作）筛选。
- **歌** — 同一首歌合并在一条，逐次列出时间、组合、成员、备注与视频。
- **大会・企划** — 大会与周边活动；日期统一为「年.月.日」，優勝 等成绩会单独标出，也能按成绩或内容筛选。
- **联动对象** — 905 人，可按年份筛选「这一年和谁玩得多」，点进个人页看共同的配信、歌曲与大会。

## 使用说明

- 右上角可切换 **日本語 / 中文**：只有界面文字会变，配信标题、人名、曲名等数据保留日语原文。
- 所有筛选条件都写在地址里，复制地址即可分享同一画面。
- 页面为深色界面，纯静态，无账号、无 cookie、无访问统计。

## 几点说明

- 时长只算「配信」本篇，切り抜き 与 Shorts 不计入；多窗联动会按窗分别计数，所以共演时长偏大。
- 2026 年的数据截止 11 月 28 日。
- 数据来自粉丝整理的「葛葉倉庫 2018–2026」，不是官方数据，漏记与名字变体可能存在。
