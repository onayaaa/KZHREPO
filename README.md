## 1. 这个网站是什么

把 2018 年出道到 2026 年的配信记录，整理成可以按人、按年、按类型检索的档案。

打开后会看到一个「概要」页，点顶部导航可以进入另外四个页面。

| 收录内容 | 数量 |

| 配信总时长 | 13,817 小时（只算配信本篇） |
| 翻唱与原创曲 | 375 次演唱，按曲名合并为 246 首 |

数据范围：**2018-03-08 〜 2026-11-26**。

## 2. 页面导览

### 概要（#/summary）
- 顶部六张数字卡：频道订阅者、配信档案、配信总时长、歌、大会・企划、コラボ相手
- 年别配信时间（点柱子直接跳到那一年的配信）
- 「あゆみ」：6 个里程碑（初ツイート、出道、ChroNoiR 结成、ゲーマーズ 出道、ド葛本社 结成、生日）
- 月别配信趋势折线（点圆点跳到对应月份）
- 配信日历热力图：默认显示最新一年，可切换年份；颜色越亮当天配信越久，鼠标悬停看「日期・时长・本数」，下面还有「表で見る」的数值表
- よく共演する相手 / よく遊ぶゲーム 排行
- 频道订阅者推移：把鼠标移到线上才显示「日期 / 人数」，不悬停时只有一条干净的曲线
- 官方链接、播放列表、关于数据的说明

### 配信アーカイブ（#/streams）
- 每张卡片：YouTube 封面 + 标题 + 时长 + 日期 + 内容标签，点一下到 YouTube
- 左侧筛选：コラボ相手 / 年 / 月 / 内容 / 種類
- 卡片左上角徽章表示这条是什么：配信 / 切り抜き / Shorts / 歌 / 公式番組 / 番組 / ライブ / 案件（案件会显示「配信 + 案件」两枚）
- 卡片内的共演者超过 3 人会折叠成「もっと見る +N」，点开看全部，再点「閉じる」收起
- 一次显示 60 条，下面「さらに表示」继续加载

### 歌（#/songs）
- **同一首歌合并在一条里**：展开后逐次列出「日期 / 组合 / 成员 / 备注 / 视频」，可以横向比较不同时间、不同组合的版本
- 筛选：分類（翻唱 / 原创）、ユニット、コラボ相手
- 备注较长时会自动换行，不会被截断

### 大会・企画（#/events）
- 两个标签页：大会 / 企划　与　周边・活动
- **優勝 会特别标出来**：冠军行有红色描边和徽章，準優勝、3 位也有各自的徽章
- 「成績」筛选：優勝 / 準優勝 / 3位 / 4〜10位 / 敗退・予選落ち / その他 / 記録なし
- 还能按「参加メンバー」筛（周边页不显示这项）

### コラボ相手（#/collabs）
- 905 人，可按**年份筛选**——「这一年和谁玩得多」
- 点某人进个人页：共演配信数 / 时长 / 一起唱过的歌 / 一起参加的大会 / 初共演 / 最終共演，还有年别柱状图、最近的配信、「一緒の曲」「一緒の大会」（按最新排序）
- 页尾「この相手で配信を絞り込む」可以一键跳到该人的配信列表

## 3. 搜索与筛选

- **顶栏搜索**（右上角）：输入名字或配信标题，会出「コラボ相手 / 配信」两组候选；↑↓ 选择、Enter 确定、Esc 关闭。没有候选时按 Enter 直接按标题搜配信。
- **侧栏 chip**：点一下筛，再点一下取消；「絞り込みをすべて解除」一次清空。
- 侧栏太长时可以单独滚动（手机上侧栏收在左上角按钮里）。
- **地址可以分享**：所有筛选都写在 URL 里，复制地址给别人就能看到同一画面。例如：
  - `#/streams?p=叶&y=2025` — 2025 年和 叶 的配信
  - `#/events?r=champion` — 只看優勝
  - `#/songs?p=椎名唯華` — 椎名唯華 参与的歌
  - `#/collabs?p=叶&y=2026` — 叶 的 2026 年

## 4. 读数据时要知道的

- **时长只算「配信」本篇**：切り抜き 和 Shorts 不计入（它们的时长另有统计）。
- 同一场大会/联动如果开了多个窗，会按窗分别计数，所以「共演时长」是偏大的口径。
- 2026 年的数据到 **11 月 26 日**为止。
- 源表里有 4 处年份疑似笔误（初ツイート、VTuber 出道、ド葛本社 结成、生日都写成了 2023/2024），站内按 2018 年修正，并在页面上标注了原值。
- 数据来自粉丝整理的「葛葉倉庫 2018–2026」Excel，不是官方数据；漏记、名字变体都可能存在（例如同一个人有两种写法）。
